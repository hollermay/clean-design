# Copy swaps (stock AI phrases to say instead)

Rule: say what the product does for a named person. If you cannot, the sentence is filler: delete it.

| Stock phrase | Instead |
|---|---|
| Supercharge your workflow | (say the job) "Turn a 6-hour stream into 10 clips." |
| Seamless integration | "Works with GitHub and Slack." (name them) |
| Revolutionize / Reimagine | delete |
| Unlock the power of | "Use X to ..." |
| Elevate your brand | what changes for the customer |
| Streamline your process | the step that gets removed |
| Cutting-edge / state-of-the-art | delete, or give the spec |
| Trusted by thousands | a real number with its source, or delete |
| Join the waitlist today! | "Get early access" + what they get |
| Made with love / Made with ✨ | delete the footer line, or a plain "(c) 2026 Name" |
| Get started in seconds | the real first step: "Paste your repo URL" |

Buttons: use a verb plus the object ("Start the free trial", "Download the skill"), not "Get started" or "Learn more" unless nothing better is true.
